# Lenny Bos — Portfolio

This website is a personal portfolio focused on my background in Cyber Security and Software Development. It presents my skills, education, work experience, projects, and contact details.

The site includes a classic portfolio view and an interactive terminal view. The terminal reflects my interest in technology and cybersecurity while giving visitors a more engaging way to explore my work. Grogu acts as a guide and helps visitors use the available commands.

If you are unsure what to do in the terminal, follow the instructions from our little green friend Grogu. You can also select **Classic view** in the top-right corner to open the normal version of the site.

The project is built with HTML, CSS, and JavaScript and runs without a backend.
